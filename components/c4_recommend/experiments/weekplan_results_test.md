# C4 research experiment – rule-based vs model-guided week plans (week planner) (test split)

Generated by `experiments/weekplan_study.py`. C3 model: `xgboost_fusion_v0.2.0_synthetic`. 366 screening sessions from 29 held-out bowlers of C3's synthetic cohort; 134 were flagged (Moderate tier or above).

Outcome = **true** 28-day injury probability from the generator's hazard model (`experiments/oracle.py`), not C3's prediction, so the what-if plan is not graded by the model that chose it. Oracle reproduction check: max error 0.0109 over 1800 recorded hazard terms.

## Does the model rank plans like the true injury mechanism? (counterfactual validity)

* For every pair of plans for the same bowler, C3's predicted 14-day risk orders them the same way as the true 28-day risk in **73%** of 1684 pairs.
* Spearman correlation between predicted and true risk reduction (vs usual week): 0.54.

## Limits of this experiment

* Synthetic cohort: shows the method works when the injury mechanism is known; it is not evidence about real bowlers.
* C3 was trained on data from the same generator, so real-world gains are expected to be smaller.
* Technique is held fixed for the planned week; weeks 2–4 return to the usual week for every policy.
* Next step: repeat with real bowler logs and physiotherapist-labelled plans (Cohen's κ, `experiments/evaluate.py`).
